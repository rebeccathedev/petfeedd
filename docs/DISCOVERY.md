# petfeedd Discovery

[README](../README.md) · [Installation](INSTALL.md) · [Configuration](CONFIGURE.md) · [API](API.md) · **Discovery** · [FAQ](FAQ.md)

You can use Bonjour/Zeroconf to discover feeders on your network.
The service is called `petfeedd` and will have a link to the API.

Use the discovered host with the endpoints in the [API reference](API.md). See [Configuration](CONFIGURE.md) for container networking and runtime setup.
